# Servidor Python y duetos · prototipo histórico

**Fuera del lanzamiento vigente.** El cliente actual exige cuenta Supabase y no inicializa `connection.js` ni salas. Python/SQLite es otro prototipo conservado para referencia; no es el servicio que sincroniza las cuentas actuales.

El `/api/session` 404 observado en el alojamiento estático pertenecía a esa ruta histórica y era independiente del ReferenceError de renderizado. No desplegar el servidor, habilitar duetos o reemplazar Supabase para corregir documentación.

Los comandos y límites de ese prototipo están en [su guía archivada](historial/SERVIDOR_Y_DUETOS_HISTORICO.md). Ejecutarlos no concede acceso a la base de Supabase ni prueba la admisión vigente.
